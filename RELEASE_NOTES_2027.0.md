# StageFlow v2027 - Windows

StageFlow est gratuit et facultatif. Préparez vos patchs, vos groupes, vos
classeurs Excel imprimables et vos plans, puis utilisez la console de la suite
si vous souhaitez réunir plusieurs outils autour du même show.

## Dans cette édition

- Trois parcours explicites : projet natif, Projet StageFlow local et
  Session StageFlow LIVE. Les autres logiciels restent autonomes.
- Une session LIVE sur le réseau local avec connexion volontaire par code à
  six chiffres, liste des postes/logiciels connectés et déconnexion manuelle.
- Télécommande par QR pour plusieurs téléphones et tablettes, avec accès aux
  télécommandes StageMark et StageMon lorsqu'elles sont prêtes sur la session.
- Alertes de changements de labels : ancien vers nouveau, origine, heure,
  compteur et bandeau persistant. L'acquittement reste local ; le maître peut
  suspendre les notifications sans couper LIVE.
- Console compacte et commandes rapides des logiciels connectés ; OSC, MIDI
  et paquet Stream Deck facultatifs, avec les protections de chaque logiciel.
- Guides FR/EN communs finalisés avec schémas, parcours et 24 commandes de
  référence. Disponibilités et limites Windows/macOS clairement distinguées.
- Remplacement Windows sans fermeture automatique des applications, sans
  suppression des dossiers/profils utilisateur ; raccourci StageFlow v2027.

## Disponibilité et précautions

Cette section décrit l'application Windows x64 autonome. StageFlow pour Mac a
depuis été ajouté à la même release v2027.0, en éditions Apple Silicon et Intel.
Consultez `RELEASE_NOTES_MACOS_2027.0.md` avant de choisir votre paquet.

Le connecteur AutoCAD 2026 pour Windows est facultatif et décoché par défaut.
Il ne contient pas de bibliothèques Autodesk. La projection, les interfaces
audio, les périphériques MIDI et les workflows dans AutoCAD doivent être
vérifiés sur votre propre installation avant exploitation.

Les commandes distantes ne contournent pas les sécurités locales. Un conflit
sur une valeur n'écrase pas silencieusement le travail d'un autre poste. Utilisez
un réseau local de confiance et ne publiez jamais les liens/code de session.

# StageFlow v2027 - Windows

StageFlow is free and optional. Prepare patches, groups, printable Excel
workbooks and plans, then use the suite console when several tools need to
work on the same show. Every application remains usable independently.

This edition provides explicit native/local StageFlow/LIVE workflows,
voluntary LAN joining with a six-digit code, a multi-controller mobile QR
portal, local label-alert acknowledgements, host notification pause, compact
suite controls, optional OSC/MIDI/Stream Deck and the finalized FR/EN guides.

This section describes the native Windows x64 application. StageFlow for Mac
was later added to the same v2027.0 release for Apple Silicon and Intel. Read
`RELEASE_NOTES_MACOS_2027.0.md` before choosing your package.
The AutoCAD 2026 Windows connector is optional and unchecked by default.
Hardware acceptance is required on your own installation. Remote commands
never bypass application safety; use a trusted LAN, not an Internet exposure.
