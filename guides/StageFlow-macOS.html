Commencer sur Mac

StageFlow est gratuit et autonome. Vous pouvez préparer un patch et un plan sans aucun autre logiciel. Chaque application de la suite reste utilisable seule.

  1. Choisissez le DMG de votre Mac : Apple Silicon pour les puces M, Intel pour les processeurs Intel. macOS 14 ou ultérieur est requis.
  2. Ouvrez le DMG et glissez StageFlow.app dans Applications. Lors d'un remplacement, enregistrez et quittez la version précédente avant de copier la nouvelle.
  3. Créez un show avec Nouveau, choisissez le nombre exact de paires et de groupes, puis enregistrez le projet.
  4. Renseignez le commun et les groupes. Une case vide peut reprendre la valeur commune ; décochez son inclusion pour la masquer uniquement dans ce groupe.
  5. Exporter Excel crée un classeur : un onglet par groupe et une page A4 paysage par groupe. Le menu Fichier permet aussi d'ouvrir un patch Excel ou d'actualiser le patch depuis le classeur du même projet.

Un projet, plusieurs outils

ParcoursÀ quoi il sert
Projet StageFlow localLe dossier .stageflow contient les domaines indépendants du patch, des plans et des autres outils. Chaque application préserve les domaines qu'elle ne possède pas.
Fichier .stageflowpackUne copie de transport en un fichier. Arrêtez le LIVE, créez la copie puis ouvrez-la dans un nouveau dossier. Ce n'est pas un support de travail simultané.
Session StageFlow LIVEUne session volontaire sur le même réseau local : le maître donne un code à six chiffres, chaque participant choisit de rejoindre ou de quitter.

Dans le Finder, un dossier StageFlow peut apparaître comme un paquet. Son contenu reste un dossier, sans conversion du format ; « Afficher le contenu du paquet » permet de l'inspecter. Vous pouvez aussi choisir le projet depuis le menu Ouvrir de StageFlow.

Saisie et plan

Entrée descend à la cellule suivante ; Tab passe à droite. Les raccourcis ⌘C / ⌘V fonctionnent avec Excel. Le petit coin de la cellule active prolonge une liste vers le bas ; le bouton « Prolonger vers le bas » permet aussi de préciser une paire finale. ⌘S enregistre.

« Plan de scène » ouvre le plan natif. Choisissez un groupe, placez ses sources et déplacez-les à la souris. Les positions et dimensions sont en millimètres. Enregistrer publie les données CAD et SVG du projet ; les exports SVG et PNG correspondent au groupe affiché. Un dessin tiers que cet éditeur ne peut pas restituer est protégé contre le remplacement.

LIVE, téléphones et alertes

Le bouton LIVE central indique clairement l'état et le nombre de postes et de mobiles. Son centre regroupe le LIVE local, la session réseau et la télécommande QR. La déconnexion ne ferme pas le projet et rend chaque application autonome. Les alertes concernent les changements de labels ; chaque destinataire acquitte ses propres alertes ou les suspend sans affecter les autres.

Dans la console du bas, choisissez le poste cible avant une commande. StageDesk prend en charge le transfert local projet + session sur Mac. StageMark peut ouvrir le projet local au démarrage ; sa connexion LIVE se fait volontairement par le réseau. Dante Config Editor ouvre aussi un projet local et rejoint le LIVE séparément. Les fonctions de StageMon dépendent des capacités annoncées par sa version connectée. Aucune application simplement lancée n'est présentée comme synchronisée.

OSC, MIDI et Stream Deck

Ouvrez Outils → Contrôles externes. L'onglet OSC donne les 24 commandes, leurs adresses modifiables, valeurs et retours d'état. Le port d'entrée par défaut est 18040, le retour 18041. 127.0.0.1 limite la réception à ce Mac ; 0.0.0.0 l'ouvre au réseau local de confiance. OSC n'a pas d'authentification : ne l'exposez pas à Internet.

L'onglet MIDI utilise CoreMIDI : actualisez les appareils, choisissez une entrée, puis associez Note, Control Change ou Program Change à une commande. Le bouton d'apprentissage reprend le dernier message reçu. Les canaux vont de 1 à 16 et les numéros de 0 à 127. Arrêtez les services avant d'enregistrer de nouveaux réglages. L'onglet Messages montre ce qui a été reçu et accepté ou refusé.

Le plugin Stream Deck Mac est inclus : installez Stream Deck 6.9 ou ultérieur, puis le plugin depuis son onglet. Démarrez OSC dans StageFlow et configurez la touche. Les commandes StageMark et StageMon exigent une connexion LIVE réelle et une capacité disponible ; le voyant d'envoi du plugin ne prouve pas à lui seul l'exécution.

Limites Mac : le connecteur AutoCAD fourni par la suite reste Windows uniquement. Les tests logiciels ne remplacent pas une vérification des interfaces MIDI, du Stream Deck, de l'audio et de la projection sur votre matériel. La signature d'intégrité du paquet ne constitue pas une notarisation Apple. Si macOS bloque une application provenant d'Internet, vérifiez d'abord la source officielle puis utilisez uniquement la procédure d'ouverture autorisée par macOS, sans désactiver ses protections globales.

Mises à jour

Aide → Vérifier les mises à jour Mac recherche le DMG stable correspondant à votre architecture. Le téléchargement est vérifié par SHA-256. StageFlow ouvre ensuite le DMG ; il ne remplace jamais seul une application en cours d'utilisation ni vos projets.

Getting started on Mac

StageFlow is free and standalone. Prepare a patch and a stage plan without any other application. Every suite application also works on its own.

  1. Choose the DMG for your Mac: Apple Silicon for M-series chips, or Intel. macOS 14 or later is required.
  2. Open the DMG and drag StageFlow.app into Applications. Save and quit the previous version before replacing it.
  3. Choose New, enter the exact pair and group counts, then save the show.
  4. Fill in common and group-specific values. Empty local cells can inherit common values; clear the inclusion checkbox to hide a common pair in one group.
  5. Export Excel creates one worksheet and one landscape A4 page per group. The File menu also imports Excel patches and refreshes the patch from the same project's workbook.

One project, several independent tools

WorkflowPurpose
Local StageFlow projectA .stageflow folder with separate patch, plan and application domains. Applications preserve domains they do not own.

Finder may show a StageFlow folder as a package. The underlying folder format is unchanged. Use “Show Package Contents” to inspect it, or open it from StageFlow's Open menu.

Editing and stage plans

Enter moves down, Tab moves right. Use ⌘C / ⌘V with Excel and ⌘S to save. Drag the active cell's small corner to extend a list, or use Fill down to enter the final pair.

Open Stage plan, select a group, place its sources and drag them into position. Coordinates and dimensions use millimetres. Save publishes project CAD/SVG data; SVG and PNG exports match the displayed group. Foreign drawings that the editor cannot faithfully reproduce are protected against replacement.

LIVE, mobile controllers and alerts

The central LIVE button shows the session state and workstation/mobile counts. Its centre manages local LIVE, network sessions and QR remote control. Leaving LIVE returns an application to standalone use. Label-change alerts remain until locally acknowledged; recipients may pause their alerts without affecting others.

Select the intended workstation in the suite console. StageDesk supports local project/session handoff on Mac. StageMark can open a local project at startup and joins network LIVE separately. Dante Config Editor also opens local projects and joins LIVE separately. StageMon controls depend on the connected version's advertised capabilities. Launching an application alone never means that it is synchronized.

OSC, MIDI and Stream Deck

Open Tools → External controls. OSC lists the 24 shared commands, editable addresses, values and feedback selections. The default input port is 18040, feedback 18041. 127.0.0.1 accepts commands only from this Mac; 0.0.0.0 accepts the trusted local network. OSC is unauthenticated: never expose it to the Internet.

MIDI uses CoreMIDI. Refresh devices, choose an input and map a Note, Control Change or Program Change to a command. Learn uses the last received message. Channels are 1–16 and message numbers 0–127. Stop services before applying changed settings. Messages shows received traffic and command results.

The Mac Stream Deck plugin is included. Install Stream Deck 6.9 or later, install the plugin from its tab, start OSC in StageFlow and configure each key. StageMark and StageMon commands require an actual LIVE connection and an enabled capability. The plugin's sending indicator is not proof of execution.

Mac limits: the suite's AutoCAD connector remains Windows-only. Software tests do not replace checks with your MIDI interfaces, Stream Deck, audio equipment and projector. Package signature integrity is not Apple notarization. If macOS blocks an Internet download, first verify the official source and use only macOS's approved opening procedure; do not disable system-wide protections.

Updates

Help → Check for Mac updates finds the stable DMG for this architecture and verifies its download against SHA-256. StageFlow then opens the DMG; it never silently replaces a running application or your projects.
